# Ebook PDF Extractor 사용 안내

Ebook PDF Extractor는 macOS 환경에서 Ebook Viewer의 화면을 페이지 단위로 캡처한 뒤, 캡처 이미지를 하나의 PDF 파일로 병합하는 프로그램입니다.

본 프로그램은 배포용 상용 제품이 아니며, 개인 사용을 목적으로 제작되었습니다.

---

## 개요

이 프로그램은 Ebook Viewer의 내부 파일을 직접 추출하거나 복호화하지 않습니다.  
대신 사용자가 지정한 화면 영역을 기준으로 페이지를 넘기며 스크린샷을 생성하고, 이를 순서대로 병합하여 PDF 파일을 생성합니다.

작업 중에는 프로그램이 마우스와 키보드 입력을 자동으로 제어합니다.  
따라서 PDF 생성이 진행되는 동안에는 사용자가 마우스 또는 키보드를 조작하지 않아야 합니다.

---

## 주의사항

DRM 정책으로 인해, 모든 Ebook Viwer에서 동작하지는 않는다.
현재까지 확인된 바로는, 알라딘 뷰어에서는 정상 동작한다. 

---

## 버전 안내

### 초기 버전

초기 버전은 수작업으로 작성 및 수정된 코드 기반으로 제작되었습니다.  
따라서 일부 환경에서는 정상적으로 동작하지 않거나 예외 상황을 충분히 처리하지 못할 수 있습니다.

### 현재 버전

현재 버전은 GPT를 활용해 작성된 코드 기반으로 구성되어 있습니다.  
다만 자동 생성된 코드 특성상 모든 환경과 상황에서 완전한 동작을 보장하지 않습니다.

사용자는 실행 결과를 반드시 직접 확인해야 하며, 필요 시 좌표, 페이지 수, 속도 설정을 조정해야 합니다.

---

## 동작 방식

프로그램은 다음 순서로 동작합니다.

1. Ebook Viewer의 현재 페이지를 기준으로 지정된 영역을 캡처합니다.
2. 다음 페이지로 이동합니다.
3. 입력한 페이지 수만큼 위 과정을 반복합니다.
4. 생성된 이미지 파일을 순서대로 정렬합니다.
5. 정렬된 이미지를 하나의 PDF 파일로 병합합니다.

이 방식은 화면 캡처 기반이므로, Viewer의 표시 상태와 사용자가 지정한 캡처 영역에 따라 결과물 품질이 달라질 수 있습니다.

---

## 저작권 관련 안내

저작권법 제30조에 따르면, 저작물을 개인적인 이용 범위 내에서 복제하는 것은 허용될 수 있습니다.

다만 생성된 PDF 파일을 타인에게 공유하거나 배포하는 경우에는 법적 책임이 발생할 수 있습니다.

본 프로그램은 개인 사용을 전제로 제공됩니다.  
생성된 PDF 파일의 사용, 보관, 공유, 배포에 대한 책임은 사용자 본인에게 있습니다.

생성된 PDF 파일은 개인적인 용도로만 사용하십시오.

# 사용 방법

## 개발자

개발자는 소스코드를 직접 확인한 뒤, 필요한 환경에 맞게 수정하여 사용할 수 있습니다.

본 프로그램은 기존 구현물을 기반으로 커스터마이징한 구조입니다.  
따라서 사용 환경, Ebook Viewer 종류, 화면 해상도, 권한 설정 등에 따라 추가 수정이 필요할 수 있습니다.

소스코드를 수정하는 경우 다음 사항을 확인하는 것이 좋습니다.

1. macOS 접근성 권한 처리
2. 화면 캡처 권한 처리
3. 마우스 및 키보드 자동 제어 로직
4. 페이지 전환 방식
5. 캡처 영역 좌표 계산 방식
6. 이미지 저장 및 PDF 병합 로직

### CLI 실행
CLI로 실행하고자 한다면, 위의 권한사항들을 손쉬운 사용에서 허용하신 후 다음 명령어를 입력하시면 됩니다.
``` python
pip install -r requirements.txt
python main.py
```
### DMG Build
Custom한것으로 dmg build하고 싶다면 다음과 같은 절차를 따라주시면 됩니다.

#### 사전 준비

- macOS 환경 (`hdiutil`, `codesign`, `osascript`는 macOS 기본 제공)
- 프로젝트 루트에서 작업 (`main.py`, `build.zsh`가 있는 디렉터리)

#### 한 번에 빌드 (권장)

`build.zsh` 하나로 의존성 설치 → 문법 검사 → 앱 번들 빌드 → 서명 → DMG 생성까지 모두 수행됩니다.

``` zsh
./build.zsh
```

위 스크립트는 내부적으로 다음을 순서대로 실행합니다.

1. `build`/`dist` 디렉터리 정리
2. `.venv` 가상환경 생성 (없을 경우) 및 활성화
3. `pip install -r requirements.txt` 로 의존성 설치 (`pyinstaller` 포함)
4. `main.py`, `permission_utils.py`, `capture_worker.py` 문법 검사 (`py_compile`)
5. `pyinstaller --clean --noconfirm EbookToPDF.spec` 로 `dist/EbookToPDF.app` 생성
6. `codesign` 으로 서명 및 검증 (기본 ad-hoc, `CODESIGN_IDENTITY` 지정 시 안정 서명 — 아래 참고)
7. `make_dmg.zsh` 실행으로 `dist/EbookToPDF.dmg` 생성

빌드가 완료되면 결과물은 다음 위치에 생성됩니다.

- 앱 번들: `dist/EbookToPDF.app`
- 설치 이미지: `dist/EbookToPDF.dmg`

#### DMG만 다시 생성

앱 번들(`dist/EbookToPDF.app`)이 이미 빌드되어 있는 상태에서 DMG만 다시 만들고 싶다면 다음을 실행합니다.

``` zsh
./make_dmg.zsh
```

이 스크립트는 `dist/EbookToPDF.app`를 스테이징 폴더에 복사하고 `/Applications` 심볼릭 링크를 추가한 뒤, 드래그-앤-드롭 설치용 레이아웃(아이콘 배치)을 적용해 압축된 `dist/EbookToPDF.dmg`를 생성합니다.
앱 번들이 없으면 먼저 `./build.zsh`를 실행하라는 안내와 함께 종료됩니다.

#### 재빌드 시 권한이 풀리는 문제 (중요)

ad-hoc 서명(`codesign --sign -`)은 **재빌드할 때마다 코드 서명 신원(cdhash)이 바뀝니다.**
macOS 권한 시스템(TCC)은 권한을 *번들 식별자 + 코드 서명 동일성* 으로 식별하므로, 같은 이름·같은 번들 id 라도
새로 빌드한 앱은 TCC 입장에서 "다른 앱"이 됩니다. 그 결과:

- 시스템 설정의 권한 토글이 **과거 빌드에 묶인 잔존 항목**을 가리켜, 새 빌드에서 화면 캡처/자동 클릭이 동작하지 않습니다.
- 앱을 삭제해도 TCC 항목은 남으며, 버전을 올려도 TCC는 버전을 키로 쓰지 않습니다. 토글을 off 해도 잔존 항목만 꺼질 뿐입니다.

**해결: 기존 권한 항목을 제거한 뒤 다시 받기.** 빌드 시 `--reset-permissions` 플래그를 주면 빌드 후 자동으로 정리합니다.

``` zsh
./build.zsh --reset-permissions
```

또는 빌드와 별개로 정리만 하려면:

``` zsh
./reset_permissions.zsh
```

이 스크립트는 이 앱이 실제로 사용하는 권한 서비스 3개만 제거합니다 — `ScreenCapture`(화면 기록),
`Accessibility`(자동 클릭/키 입력), `ListenEvent`(입력 모니터링).
정리 후 앱을 다시 실행하면 권한을 새로 요청합니다.
ad-hoc 빌드 특성상 새 빌드는 매번 새 신원이므로, **재빌드 후 권한이 풀렸다면 다시 `--reset-permissions` 로 정리**하면 됩니다.

#### 빌드 결과 확인

서명/권한 동작은 내부 바이너리를 직접 실행하기보다 앱 번들을 통해 확인하는 것이 정확합니다.

``` zsh
open -n "dist/EbookToPDF.app"
```

#### 참고

- `EbookToPDF.spec` 는 PyInstaller 빌드 설정 파일입니다. 앱 이름, 아이콘, 포함 리소스 등을 변경하려면 이 파일을 수정하십시오. 권한 리셋에 쓰이는 번들 식별자(`com.local.ebooktopdf`)도 이 파일의 `bundle_identifier` 값과 `reset_permissions.zsh` 의 `BUNDLE_ID` 가 일치해야 합니다.
- 본 빌드는 ad-hoc 서명(`codesign --sign -`)을 사용하므로 Apple 공증(notarization)은 적용되지 않습니다. 따라서 다른 사용자의 Mac에서 처음 실행할 때 Gatekeeper 경고가 표시될 수 있으며, `우클릭 → 열기` 또는 보안 설정에서 실행을 허용해야 할 수 있습니다.
- 코드를 수정한 경우 `./build.zsh` 를 다시 실행하면 변경 사항이 반영된 앱과 DMG가 새로 생성됩니다.

## 사용자

사용자는 DMG 파일을 다운로드한 뒤 프로그램을 실행하면 됩니다.  
아래 절차를 순서대로 진행하십시오.

---

### 1. 권한 허용

프로그램 실행 후 권한 관련 버튼이 여러 개 표시될 수 있습니다.

일반 사용자는 상단에 위치한 권한 요청 버튼 2개만 사용하면 됩니다.

권한 허용은 프로그램이 다음 기능을 수행하기 위해 필요합니다.

1. 화면 캡처
2. 마우스 및 키보드 자동 제어

권한이 정상적으로 허용되지 않으면 PDF 생성이 제대로 동작하지 않을 수 있습니다.

---

### 2. 좌표 지정

좌표 지정은 PDF로 변환할 페이지 영역을 설정하는 단계입니다.

다음 순서로 진행하십시오.

1. Ebook Viewer에서 캡처할 페이지 영역의 좌상단을 클릭합니다.
2. 캡처할 페이지 영역의 우하단을 클릭합니다.

지정된 두 좌표를 기준으로 사각형 영역이 설정되며, 프로그램은 해당 영역만 페이지 이미지로 캡처합니다.

좌표를 지정하기 전에 Ebook Viewer에서 여러 페이지를 넘겨보며 실제 콘텐츠 영역을 확인해야 합니다.  
일부 Viewer에서는 페이지마다 콘텐츠의 가로 너비가 일정하지 않을 수 있습니다.

좌표를 너무 좁게 지정하면 페이지 일부가 잘릴 수 있습니다.  
좌표를 너무 넓게 지정하면 불필요한 여백이나 Viewer UI가 PDF에 포함될 수 있습니다.

---

### 3. 페이지 수 입력

Ebook Viewer에서 전체 페이지 수를 확인한 뒤, 프로그램에 입력합니다.

입력한 페이지 수만큼 캡처가 반복됩니다.

페이지 수를 실제보다 적게 입력하면 PDF가 중간 페이지에서 종료됩니다.  
페이지 수를 실제보다 많이 입력하면 마지막 페이지 이후에도 캡처가 계속 시도될 수 있습니다.

정확한 페이지 수를 입력하는 것이 중요합니다.

---

### 4. PDF 파일명 입력

생성할 PDF 파일명을 입력합니다.

입력한 이름은 결과 PDF 파일명으로 사용됩니다.  
파일을 쉽게 식별할 수 있도록 책 제목 또는 작업 목적을 반영한 이름을 사용하는 것이 좋습니다.

---

### 5. 속도 설정

페이지 전환 및 캡처 사이의 대기 시간을 설정합니다.

기본값은 0.5초입니다.

일반적인 환경에서는 기본값 사용을 권장합니다.  
테스트 결과, 0.5초 설정이 가장 안정적으로 동작했습니다.

속도를 너무 빠르게 설정하면 페이지 전환이 완료되기 전에 캡처가 실행될 수 있습니다.  
속도를 너무 느리게 설정하면 전체 PDF 생성 시간이 길어집니다.

Viewer 반응 속도가 느리거나 페이지 전환 애니메이션이 긴 경우에는 값을 조금 높여 설정하십시오.

---

### 6. PDF 생성

모든 설정을 완료한 뒤 `Create PDF` 버튼을 클릭합니다.

버튼을 클릭한 후에는 작업이 완료될 때까지 마우스와 키보드를 조작하지 마십시오.

프로그램은 PDF 생성을 위해 마우스 및 키보드 입력을 자동으로 수행합니다.  
사용자가 다른 창을 클릭하거나 포커스를 변경하면 자동 입력이 의도하지 않은 위치에서 실행될 수 있습니다.

PDF 생성 중에는 다음 행동을 하지 마십시오.

1. 다른 앱 클릭
2. 창 이동
3. 키보드 입력
4. 마우스 이동 및 클릭
5. Ebook Viewer 포커스 변경

작업이 완료될 때까지 현재 상태를 유지하는 것이 가장 안전합니다.

---

### 7. PDF 열기

PDF 생성이 완료되면 `Open PDF` 버튼을 통해 결과물을 확인할 수 있습니다.

결과 확인 시 다음 항목을 점검하십시오.

1. 전체 페이지가 포함되었는지
2. 페이지 순서가 올바른지
3. 페이지 일부가 잘리지 않았는지
4. 불필요한 Viewer UI나 여백이 포함되지 않았는지
5. 동일한 페이지가 중복 캡처되지 않았는지

문제가 있는 경우 좌표, 페이지 수, 속도 설정을 조정한 뒤 다시 생성하십시오.

---

## 문제 발생 시 확인 사항

PDF 결과물이 정상적이지 않은 경우, 대부분 다음 항목 중 하나가 원인입니다.

1. 캡처 좌표가 정확하지 않음
2. 페이지 수가 실제와 다름
3. 페이지 전환 속도보다 캡처 대기 시간이 짧음
4. 작업 중 사용자가 마우스 또는 키보드를 조작함
5. Ebook Viewer 창의 포커스가 변경됨
6. macOS 권한이 정상적으로 허용되지 않음

각 항목을 확인한 뒤 다시 실행하십시오.

---

## 사용 시 주의사항

이 프로그램은 화면 캡처 기반 자동화 도구입니다.  
따라서 Viewer 구조, 화면 해상도, macOS 권한 설정, 페이지 전환 속도에 따라 결과가 달라질 수 있습니다.

프로그램은 모든 Ebook Viewer에서의 동작을 보장하지 않습니다.  
또한 생성 결과물의 품질과 정확성은 사용자가 지정한 설정값에 영향을 받습니다.

PDF 생성 후에는 반드시 결과물을 직접 확인하십시오.

---

## 최종 안내

Ebook PDF Extractor는 macOS에서 Ebook Viewer 화면을 페이지 단위로 캡처하여 PDF로 병합하는 개인용 도구입니다.

생성된 PDF 파일은 개인적인 목적으로만 사용해야 합니다.  
타인에게 공유하거나 배포할 경우 법적 책임이 발생할 수 있습니다.

본 프로그램의 사용 결과와 생성된 PDF 파일의 관리 책임은 사용자 본인에게 있습니다.
